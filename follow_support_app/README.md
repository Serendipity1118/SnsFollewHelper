# follow_support_app

SNSプロフィールの手動確認作業を支援するアプリのFlutter雛形です。

Windowsの開発手順と検証結果は[開発環境](../docs/DEVELOPMENT.md)を参照してください。
Androidビルド時は、リポジトリの`初期設定`という日本語パスを避けるため、
`scripts/Enter-FlutterDev.ps1`で割り当てた英数字のドライブから開発します。

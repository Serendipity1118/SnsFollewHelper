# SnsFollowHelper

X / Instagramの対象リストと手動の作業結果を端末内で管理するFlutterアプリです。
SNSの自動操作、認証情報の取得、外部Backendはありません。

- アプリ: `follow_support_app/`
- 最新の確定仕様: [要件決定事項](docs/要件決定事項.md)
- 開発・起動: [DEVELOPMENT](docs/DEVELOPMENT.md)
- 実装と検証: [実装完了報告](docs/IMPLEMENTATION_REPORT.md)
- 人が動かすテスト: [手動テスト手順](docs/MANUAL_TEST.md)
- 署名済みストアビルド: [Codemagic設定](docs/CODEMAGIC.md)

Windowsでは `scripts/Enter-FlutterDev.ps1` で英数字のドライブパスを用意してください。
開発・検証端末は既存の `Pixel_9a_Large` を使用します。

# Store Listing (English Draft)

## App name
SnsFollowHelper

## Short description
Manage social profile review targets, progress, and history locally on your device.

## Description
Import a pre-prepared list of social profile targets and manage them one by one.

Any action on a third-party social network is performed manually by the user in the external app or browser. This app does not automate social-network actions, scrape third-party services, inspect third-party app UIs, or retrieve follow status automatically.

Key features:
- CSV import
- X and Instagram targets with multiple operating-account labels
- Target list, search, and filters
- Eight manual result categories
- Work history
- Per-account rolling one-hour and 24-hour safety margins
- CSV export and ZIP backup with additive restore
- Recovery of unfinished manual result entry
- Fictional sample data that never opens an external profile
- Local-only data storage

This app is not affiliated with, endorsed by, or sponsored by X, Instagram, Meta, or other third-party social-network services.

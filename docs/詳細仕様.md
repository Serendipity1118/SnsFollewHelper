## 6. SafetyPolicy

```dart

  final int rolling1hFollowLimit;
  final int sessionFollowLimit;
  final Duration minProfileOpenInterval;
  final int consecutiveFollowLimit;
  final Duration forcedBreakDuration;

```

MVP初期値:

```dart
const defaultSafetyPolicy = SafetyPolicy(
  rolling24hFollowLimit: 20,
  rolling1hFollowLimit: 5,
  sessionFollowLimit: 10,
  minProfileOpenInterval: Duration(seconds: 60),
  consecutiveFollowLimit: 5,
  forcedBreakDuration: Duration(minutes: 10),

```

これはX / Instagramが保証する安全値ではない。

## 7. SafetyGuard

### 7.1 責務

新しいプロフィールを外部起動してよいかを判定する。

```dart
Future<SafetyDecision> canOpenNextProfile({
  required PlatformType platform,
  required WorkSession session,
});
```

### 7.2 判定順

```text
1. 強制休憩中か
2. 直近のprofileOpenedから60秒以上経過しているか
3. 過去1時間のfollowed件数 < 上限
4. 過去24時間のfollowed件数 < 上限
5. セッションfollowed件数 < 上限
6. 連続followed件数 < 上限
```

### 7.3 SafetyDecision

```dart
sealed class SafetyDecision {}

class SafetyAllowed extends SafetyDecision {}

class SafetyBlocked extends SafetyDecision {
  final SafetyBlockReason reason;
  final DateTime? retryAt;
}
```

理由:

```text
forcedBreak
minimumInterval
rolling1hLimit
rolling24hLimit
sessionLimit
```

## 10. App Lifecycle

作業画面State:

```dart
class WorkState {
  final String? currentTargetId;
  final bool externalLaunchPending;
  final bool awaitingManualResult;
}
```

プロフィール起動直前:

```text
externalLaunchPending = true
awaitingManualResult = false
```

アプリが`resumed`:

```text
externalLaunchPending == true
```

の場合:

```text
externalLaunchPending = false
awaitingManualResult = true
```

これ以上の自動処理は禁止。

## 11. 手動結果登録

利用者が結果ボタンを押した時だけ状態更新する。

```dart
Future<void> updateTargetStatus(
  String targetId,
  TargetStatus newStatus,
)
```

`followed`の場合:

```text
status = followed
processedAt = now
followedAt = now
```

その他:

```text
status = selectedStatus
processedAt = now
followedAt = null
```

同時に`statusChanged`をaction_logsへ追加する。

### 11.1 状態再変更

詳細画面から手動変更可能。

例:

```text
followed -> notFollowed
```

の場合も履歴を残す。

安全制御のfollow件数は「現在status」ではなく`statusChanged -> followed`のイベントを基準にすると重複計上し得るため、MVPでは以下とする。

- `followedAt`が存在する現在のtargetsをローリング集計
- followedから別状態へ変更された場合`followedAt = null`
- 再度followedにした場合、新しい時刻で`followedAt = now`

## 23. ストア審査対応 実装詳細

### 23.1 AboutScreen
`AboutScreen`を追加し、アプリ目的、自動操作を行わない旨、非提携表記、プライバシーポリシー導線を表示する。

### 23.2 サンプルデータ
`SampleDataService`を追加する。

```dart
abstract interface class SampleDataService {
  Future<SampleImportResult> installSampleData();
  Future<void> removeSampleData();
}
```

Targetsへ以下を追加する。

```text
isSample BOOLEAN NOT NULL DEFAULT false
```

サンプル対象から実在SNSプロフィールを開かない。

### 23.3 外部起動フォールバック
HTTPS URLを`LaunchMode.externalApplication`でOSへ委譲する。起動不能時のみエラー表示する。独自URL Schemeのみへ依存しない。

### 23.4 プライバシー
MVPでは以下を追加しない。

```text
Firebase Analytics
Google Analytics
Facebook SDK
Adjust
AppsFlyer
広告SDK
独自クラッシュ送信Backend
```

導入時はプライバシーポリシー、App Privacy、Data Safetyを再確認する。

### 23.5 Manifest / Entitlements確認
Android:
```text
AccessibilityService宣言なし
QUERY_ALL_PACKAGESなし
不要なPACKAGE_USAGE_STATSなし
```

iOS:
```text
不要なURL Scheme列挙なし
不要なTracking権限なし
追跡しない場合はNSUserTrackingUsageDescriptionなし
```

```text
docs/
```

# ストア掲載文（日本語ドラフト）

## アプリ名
SnsFollowHelper

## 短い説明
SNSプロフィール確認作業の対象・進捗・履歴を端末内で管理する作業支援アプリです。

## 説明
事前に用意したSNSアカウント一覧を取り込み、確認対象を1件ずつ管理できます。

プロフィールの確認やフォロー等の操作は、利用者自身が外部SNSアプリまたはブラウザ上で行います。本アプリはSNSの操作を自動化せず、第三者SNSの画面解析、スクレイピング、フォロー状態の自動取得も行いません。

主な機能:
- CSVインポート
- X / Instagram、複数の運用元ごとの担当管理
- 対象一覧・検索・絞り込み
- 8種類の手動ステータス管理
- 作業履歴
- 運用元別のローリング1時間・24時間安全マージン
- CSVエクスポートとZIPバックアップ・追加型復元
- 作業中断後の結果入力復元
- 外部サイトを開かない架空サンプルデータ
- 端末内ローカル保存

本アプリはX、Instagram、Meta等とは提携・承認・後援関係にありません。

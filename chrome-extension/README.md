# フォロー補助（Chrome拡張）

ローカルWebサービス（[`web-service/`](../web-service/README.md)）から開いた X のプロフィールタブを整理する拡張。

## 方針（厳守）

- **フォローボタンは絶対に自動で押さない。** フォローは必ず人が押す。
- 拡張がするのは次の3つだけ。
  1. 開いている X のプロフィール画面の**表示を読み取る**
  2. タブを閉じる
  3. 結果をローカルのWebサービス（`http://127.0.0.1:8787`）へ知らせる
- 結果は外部へ送らない（送信先は `127.0.0.1` / `localhost` のみ）。

## 動き

対象は X のプロフィールのトップ（`https://x.com/<handle>`）を開いているすべてのタブ。

| 画面の状態 | 動き | Webサービスへの記録 |
|---|---|---|
| アカウントが存在しない | 15 秒後に閉じる | 死垢 |
| 凍結されている | 15 秒後に閉じる | 死垢 |
| すでにフォロー中／承認待ち | 15 秒後に閉じる | 既フォロー（画面では「フォロー済みだった」。上限の件数に数えない） |
| 未フォロー | **残す** | — |
| 人がフォローを押した | 表示が「フォロー中」（鍵垢は「承認待ち」）に変わってから 1.5 秒後に閉じる | 済 |
| 読み込みエラー・判定できない | 残す | — |

- 名簿にない handle（Webサービスが 404 を返す）は、記録せずにタブだけ閉じる。
- Webサービスが止まっている・拒否したときはタブを残し、画面右下にエラーを表示する。
  フォローを押した後に記録に失敗した場合は、Webサービスを起動してからそのタブを再読み込みすると「済」で記録し直す。
- 「15 秒後」は、開いたタブで状態が分かった時点から数える（オプションで変更可）。
- 待ち時間中にフォローを解除した・別の画面へ移った場合は閉じない。

## 導入

1. Webサービスを起動する（`cd web-service && npm run dev`）。
2. Chrome で `chrome://extensions` を開き、右上の「デベロッパー モード」をオンにする。
3. 「パッケージ化されていない拡張機能を読み込む」でこの `chrome-extension/` フォルダを選ぶ。
4. 拡張のIDが `liiicjpegnmagfdlnmbnebdfkdkjjlpl` であることを確認する（`manifest.json` の `key` で固定）。
   Webサービスはこの ID からの書き込みだけを受け付ける。別IDで読み込んだ場合は、Webサービスを環境変数 `EXTENSION_ID` 付きで起動する。

## 使い方

- ツールバーの拡張アイコンをクリックすると **ON/OFF** が切り替わる（バッジに表示。初期値は ON）。
  普段の閲覧中はフォロー済みの相手を開くとタブが閉じるので、必要に応じて OFF にする。
- 拡張アイコンを右クリック →「オプション」で、次の2つの秒数と Webサービスの URL を変えられる。
  - フォローしてから閉じるまでの秒数（0〜10秒、初期値 1.5 秒）
  - 存在しない・凍結・フォロー済みのタブを閉じるまでの秒数（0〜60秒、初期値 15 秒。0 にすると従来どおりすぐ閉じる）

## 開発

```powershell
cd chrome-extension
npm install
npm test            # vitest + jsdom
```

- `src/detect.js`: X の画面構造に依存する判定はすべてここ。X の画面が変わって判定が壊れたらここを直す。
  使っている目印: `[data-testid="primaryColumn"]`、`[data-testid="emptyState"]`、`[data-testid$="-follow" / "-unfollow" / "-cancel"]`、ボタンの `aria-label` の `@handle`。
- `src/content.js`: 判定と人のクリックの検知。`src/background.js`: 記録とタブのクローズ、ON/OFF。
- `test/content.test.js` は、拡張のコードに `.click()` や `dispatchEvent` が無いことも検査する。
